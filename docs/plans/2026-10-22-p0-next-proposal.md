2026-10-22 用户批准「本地模型对照及通过后接入」；帧率选择「egolite 后台测试」。A 的模型下载、私有转换依赖和本地对照现已开始。没有新增前端运行时或付费 AI 调用，也没有启动补充浏览器。后台测量单独标注条件，不降低 45 FPS / 30 分钟的门槛。

当前候选已用冻结的九段独立表演在 Ego Lite 复测：七段达到 ≥80% 覆盖率 / ≤5 秒首次识别；爵士吉他为 66.3%，历史吉他为 26.5% / 14.6 秒。已识别窗口没有错误乐器；语音、白噪声和静音没有乐器预测。不能据此标记乐器 P0 全部通过。

正常接电、低电量模式关闭时，隔离对照的 2D、WebGL（保留/丢弃绘图缓冲）和 p5 WebGL 都约 30 FPS；无画布对照约 60 FPS。对照没有音频、分类 Worker、弹幕或 SonoScope shader。因此应用之外的呈现/调度路径需要继续隔离，尚不能断言是 Ego Lite 的固定上限，也不能通过降低画质宣称修复。30 分钟 / 95% 秒窗口 ≥45 FPS 的门槛保留。

## A. 替代模型的本地对照

建议先比较现有 YAMNet 与 EfficientAT `mn04_as`。作者发布的候选约 0.983M 参数、AudioSet mAP 43.2，代码为 MIT；这不是本项目准确率保证。[作者仓库与模型表](https://github.com/fschmid56/EfficientAT#pre-trained-models)。其官方前处理为 32 kHz、128 个 mel 频带，须精确复现，不能只改采样率或重命名标签。[官方前处理](https://github.com/fschmid56/EfficientAT/blob/main/models/preprocess.py)。

MusicNN 的 MTT 模型也覆盖吉他/钢琴/鼓等音乐标签，但词表仅 50 项，不能直接代替现有完整乐器和声音事件分类，因此本次不作为直接替换项。[作者词表说明](https://github.com/jordipons/musicnn/blob/master/FAQs.md)。

| 模块 | 拟议变化与接口边界 |
| --- | --- |
| 私有实验目录 | 下载固定版本的一个候选，验证原始浮点结果；先测 2 秒窗口，400 ms 推进。必要的转换依赖仅装在项目私有环境，保留版本和校验值。 |
| 模型转换 | 优先导出带准确前处理和标签元数据的 TFLite，复用当前 MediaPipe。若需要不支持的算子或新增浏览器运行时，停止该路径并另行确认；不直接引入 ONNX Runtime / TensorFlow.js。 |
| FeaturePipeline / 分类 Worker | 仅在候选通过后引入带版本的模型规格（采样率、窗口样本数、推进样本数）；仍然一个分类 Worker、一个在途推理、有界 PCM 和超时降级。生产配置只加载最终选定的一个模型。 |
| ModelResult / 弹幕 / 服务端 | 保持 v2 公共字段和单弹幕队列；保留声源切换清空、证据过期、语音/噪声反例与限定语。候选的分数资格需独立校准，不能把不同模型的分数相加或当作相同概率。 |

验收仍要求：旧九段失败保留并复测；另冻结未参与选型与校准的新表演集（至少六段，含停顿和录音噪声），每段 ≥80% 正确覆盖、首次 ≤5 秒，未知计为失败，三个反例零乐器。实测模型资源目标 ≤8 MiB、分类计算 p95 ≤100 ms，PCM 队列 <1 MiB；这些是筛选门槛，不是已测结果。记录冷启动、Worker/总内存及资源释放，不用主页面 JS 堆冒充总内存。若转换或资源/准确率门槛失败，不接入应用。

该批准仅覆盖本地候选对照、必要的私有转换环境，以及通过全部验收后接入现有 MediaPipe 路径。没有付费 AI 调用，不部署；如果需要新增浏览器运行时或进一步扩大资源范围，重新确认。
