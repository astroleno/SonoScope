# SonoScope 性能与沉浸体验复测 · 2026-11-25

默认隐藏工具栏适合把注意力留给画面。上一版的主要割裂感来自录制结果藏在工具栏后面，以及首条弹幕在显示空间短暂不足后可能等上十几秒。旧版完整测试还观察到录制首条 p95 为 1.20 秒，桌面 45 FPS 门槛未通过。[基线报告](2026-11-24-desktop-validation.md)

## 本轮改动与证据

| 检查 | 实测 |
| --- | --- |
| Wave 画面 | Apple M4 的 Chromium WebGL 在 1280 × 720 和 320 × 568 分别比较安静、中等、强音、最大振幅和细线，10 组 RGBA 像素逐通道相同。生产绘制仍使用完整画布与既有录播时钟。 |
| Wave 绘制开销 | 1280 × 720 的硬件 GPU 查询，每种条件每版 8 组、每组 6 次绘制。安静条件 GPU 中位耗时为 0.087 → 0.061 ms，中等为 0.087 → 0.082 ms，强音为 0.087 → 0.088 ms。该指标测量独立着色器。 |
| 弹幕恢复 | 固定声源、相同模拟时钟和可渲染条件下，画面在 3.30 秒恢复显示空间。上一版首条在 12.08 秒显示，本版在 3.30 秒显示。冷却从实际呈现回执开始。低音结束后间隔静音再起高音的用例也通过，恢复时不会先显示已失效的低音描述。 |
| 隐藏界面 | 输入电平表只在界面展开时订阅。紧凑录制控件与展开的工具栏共用弹幕避让边界。保存结果显示约 4 秒后退出，错误保留提示和适用的录播入口。停止录制后键盘焦点返回菜单。 |
| 工程检查 | 正式回归首跑 272/274。两项已有服务器和画布生命周期测试等待超时，定向复跑的两套测试共 18/18。兼容 47/47，代码规范和类型检查通过。本地测试副本关闭 webpack 构建缓存以节省磁盘，生产构建、离线准备和独立产物冒烟通过。 |

## 全页复核

在同一台 Mac 的 Chromium 交错运行两版本地产品构建。普通和录制各用三段相同文件，合计 12 次。较早的文件选择器试跑受到页面隐藏干扰，记录一并保留，未计入有效对照。

| 全页指标 | 上一版 | 本版 |
| --- | ---: | ---: |
| 普通首条中位数 | 90 ms | 363 ms |
| 录制首条中位数 | 537 ms | 315 ms |
| 普通画布帧率，各次中位数的中位数 | 21 FPS | 22 FPS |
| 录制画布帧率，各次中位数的中位数 | 6 FPS | 22 FPS |
| 达到 45 FPS 的完整秒 | 0/30 | 0/28 |

录制的三个复测样本首条为 239–479 ms，普通组中位数反而上升。样本少且单次 FPS 波动大，保留正式的 1 秒 p95 和 45 FPS 验收缺口。已验证的双向频段变化分别在 568 ms、161 ms 出现对应弹幕，38 秒稳定音全页试跑因浏览器无响应中断，自动化稳定音用例通过。

320 × 568 模拟视口复核了默认隐藏、录制状态与停止入口、文字与底栏避让、停止后成功保存、焦点返回菜单和 H 恢复面板。另在 1470 × 739 视口播放同一文件，确认五个预设均打开画布，切换过程中音频保持运行。当前数据来自桌面和模拟视口，实体麦克风与移动设备体验仍待实测。[紧凑录制画面](../artifacts/immersive-recording-20261125.png) · [逐次数据](../artifacts/immersive-performance-20261125.json)
