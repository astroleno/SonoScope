# SonoScope 整页帧率与首条弹幕复测 · 2026-11-25

## 原因定位

- 在同一台 Mac 的 Ego Chromium，测试页可见且有焦点。无 SonoScope 的最小 HTML 和 WebGL 绘制，浏览器 rAF 间隔中位数已约 33.3 ms。实际 Wave 播放时，画布绘制与 rAF 同频，间隔约 33.3 ms，探针未记录到超过 50 ms 的主线程长任务。这次整页约 30 FPS 的上限来自当前浏览器环境提供的绘制回调频率。该结果限于本次测试环境。
- 上轮普通播放只有三对样本。两段更快，只有 Pistachio 从 90 ms 变成 374 ms。同一版在这次剖析中为 53 ms，其中源起声后约 21 ms 已有达到阈值的特征，约 43 ms 插入弹幕。历史慢例未重现，先前日志不足以区分漏过起音帧、调度或显示等待。
- 可重复的慢例是 Nutcracker 的渐强起声。旧版源起声后约 43 ms 已收到强声特征，持续性弹幕约 280 ms 才入 DOM，约 299 ms 可见。旧的 240 ms 连续声音等待解释了主要延迟。

## 改动

- 默认本地模式首条可使用 128 ms 连续强声作为持续性的证据。至少需要四帧相邻、时间向前且间隔有界的有效强声。较弱的输入、跳帧或时钟异常不能为这条路径累积证据。已展示首条后使用原确认和节奏规则。
- 音频特征历史在原数组内保留 2.2 秒及最近 120 帧。每个已发布特征省去两次数组分配，保留历史乱序和边界行为。回归测试将聚合输出逐项与原算法对比。
- 使用相同画布分辨率、Wave 绘制和沉浸界面。现有视觉、录播、边界避让、静音和短声回归一起运行。
